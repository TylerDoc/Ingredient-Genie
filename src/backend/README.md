# Ingredient Genie Backend

The Ingredient Genie backend provides the JSON REST API and SQLite data storage used by the frontend.

## Default Startup

```text
1. Extract the release archive.
2. Open a terminal and change into the extracted directory.

   cd ingredient-genie-backend_<version>_<os>_<arch>

3. Run the backend.

   Windows:
   ingredient-genie-backend.exe

   Linux/macOS:
   ./ingredient-genie-backend

4. If prompted by the operating system or firewall, allow network access.

The backend listens on port 4242 by default and uses meals.sqlite in the current directory.
```

Use `-help` to view available configuration options.
