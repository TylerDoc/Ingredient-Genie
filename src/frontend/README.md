# Ingredient Genie Frontend

The Ingredient Genie frontend provides the browser-based interface for searching, creating, viewing, updating, and deleting meals.

## Default Startup

```text
1. Make sure the Ingredient Genie backend is already running.

2. Extract the frontend release archive.

3. Open a second terminal and change into the extracted directory.

   cd ingredient-genie-frontend_<version>_<os>_<arch>

4. Run the frontend.

   Windows:
   ingredient-genie-frontend.exe

   Linux/macOS:
   ./ingredient-genie-frontend

5. If prompted by the operating system or firewall, allow network access.

The frontend listens on port 4243 by default and connects to:
http://localhost:4242
```

Open `http://localhost:4243` in a browser.

Use `-help` to view available configuration options.
